# Wave 7 ports: eval sets and pre-registered decision rules

**Status:** pre-registered 2026-10-29, before any comparison run. Results are appended under §Results; the rules
below are not edited after the first live run (a changed rule is a new section with its reason).

Concept §11: every phase moves a caller and deletes the old path. A port's skill switches only after its rule
below passes. Eval cases are private (`$AGW_EVAL_DIR/<workflow>/cases.jsonl`, never in git). Eval runs use the
team key; deploy verification the personal key. Legacy arms run on agent-gateway as it is deployed.

## otel

- **Cases:** 8 investigations (≥ 6 against prod ClickStack), each over a fixed absolute time window. Per case a
  reference written **before any arm runs**, from direct ClickHouse queries: the expected `status`
  (`healthy|degraded|errors`) and 1–3 key facts (a service, an error class, a latency figure).
- **Arms:** L = agent-gateway `otel` (as deployed), 1 run per case. N = `agw otel` on its default route, 2 runs per case.
- **Scores:** `valid` (output schema), `status` (match), `facts` (share of reference facts present, judged),
  `grounded` (N only: every finding's evidence traces to a query made in the same run). Cost and wall per run.
- **Rule:** N passes if mean `facts`(N) ≥ mean `facts`(L) − 0.10 **and** `status` accuracy(N) ≥ accuracy(L) − 1/8
  **and** every N run has a priced cost. If N fails on the default route, arm N2 = the same on route
  `claude-sonnet-5-5-eu` (IU) under the same rule; the cheapest passing arm wins. None passes → `/otel` does
  not switch; the lead reports with the numbers.

## brain

- No legacy path exists (agent-gateway has no brain agent), so no side-by-side. The baseline is absolute.
- **Cases:** 10 questions over `wiki/`, `Areas/` and `Projects/` of the vault, each with the reference note
  path(s) and 1–3 key facts, written before any run.
- **Rule:** reference note cited in ≥ 8/10, mean `facts` ≥ 0.8 (judged), **zero** citations of a path the run did
  not read or that does not exist, median cost ≤ $0.01. A miss is fixed by the prompt or tools, not by a model
  change without a new rule.

## diagram (excalidraw)

- **Cases:** 6 briefs: the legacy bench brief, an architecture diagram, a flow, an extend-mode case on an
  existing drawing, German labels, a dense one (≥ 20 nodes).
- **Arms:** L = agent-gateway `excalidraw_diagram`, 2 runs per brief. N = `agw diagram`, 2 runs per brief.
- **Scores (deterministic):** `valid` (hydrates to a v2 `.excalidraw` document), element count, bound-arrow share
  (both ends bound to existing ids), shape overlaps (bounding-box intersections between non-container shapes),
  text overflow (label wider than its container by the hydrated width). Cost and wall per run.
- **Rule:** N passes if valid rate(N) ≥ valid rate(L), mean bound-arrow share(N) ≥ L − 0.05, mean overlaps(N) ≤
  L + 1, median cost(N) ≤ 1.5 × median cost(L).

## prose

- The rewrite moves into the calling session on Max (concept §10); the workflow is lint + cross-lab review +
  keep gate. Legacy's writer has no counterpart to compare.
- **Cases:** the 4 recorded legacy jobs (full input and result) plus 6 drafts covering article (EN), vault (DE),
  landing, ui, briefing, docs.
- **Rule, all four:**
  1. Lint: N's findings equal legacy lint's (`prose-lint.ts`, run directly, no LLM) on all 10 drafts.
  2. Keep gate: on the 4 recorded (original, rewrite) pairs plus synthetic negatives (a lost URL, an added
     fence, a worsened lint rule, a format switch), N's keep decision equals legacy `judgeRewrite`'s on 100 %.
  3. Review: N run twice per draft; per criterion, mean |score(N) − score(L recorded)| ≤ max(0.5, N's own
     run-to-run mean |diff|) averaged over criteria, on the drafts with a recorded legacy review.
  4. Cost per N call ≤ 1.2 × legacy's review-call cost (the writer's spend moves to Max; both reported).
