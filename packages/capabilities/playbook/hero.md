# Hero / Banner / Cover Images

The general recipe for a hero, banner, or cover image — a blog post's hero image specifically is `article.md`; a painterly journal-cover series is `painterly.md` for the medium vocabulary, this file for the layout discipline.

- Use case first: state the intended placement ("hero banner", "landing-page cover", "wallpaper") — it sets composition and polish level.
- Reserve negative space deliberately for what will sit on top of the image: _"strong negative space above/beside for title text; clear silhouette that reads at thumbnail size"_.
- Prefer generating without embedded text and overlaying typography in post-production — more flexible than baking text in. If text must be in-image, follow `core.md`'s "Text in images" rules exactly (quoted text, spelled-out typography).
- Template: `Create [type] for [use case]. Main subject: [...]. Composition: [framing, negative space]. Style and lighting: [...].` plus the target size.
