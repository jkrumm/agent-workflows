# Sharp / Technical (Product, UI, Isometric)

Product renders, UI mockups, and isometric/exploded technical art. Diagrams and infographics are their own recipe — see `diagram.md`.

- Product: _"Modern minimalist product photo of [PRODUCT] on [SURFACE], soft window light from the left, neutral background, shallow depth of field, professional product photography"_ + material cues (_matte black ceramic, condensation droplets, sharp catchlights, subtle drop shadow_).
- UI mockups: _"Flat design illustration of a [domain] dashboard mockup with [components]... modern SaaS branding"_; name the platform idiom (_"realistic iOS-style status bar"_, _"Material Design 3"_); for flows, describe each screen individually (_"four phone screens arranged horizontally with arrows connecting each step"_).
- Isometric: strict projection is unreliable and drifts across iterations. Use _"professional 3D game art style, consistent 45-degree angle"_ as the cue; exploded views work (_"exploded assembly view"_, _"transparent cutaway"_). Precise engineering drawings need post-cleanup — say so rather than promising.
