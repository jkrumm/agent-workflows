# Article / Blog Hero Images

The blog/article-specific case of `hero.md` — same negative-space discipline, narrowed to the editorial-post use case.

- Use case first: _"hero banner for a blog post about X"_.
- Reserve negative space deliberately: _"strong negative space above for title text; clear silhouette that reads at thumbnail size"_.
- Prefer generating without embedded text and overlaying typography in post. If text must be in-image: quote it exactly and specify font feel, weight, color, placement (see `core.md`'s "Text in images").
- Template: `Create [type] for [use case]. Main subject: [...]. Composition: [framing, negative space]. Style and lighting: [...].` plus the target size.
- Article art is typically exploratory and cheap: draft several at `quality: low` with a higher `n`, pick, then promote only the winner to `high` — see `settings.md`'s cost anchors.
